# 포물선 운동 영상 분석 (projectile-tracker)

고등학교 「역학과 에너지」 수행평가용 웹 앱. 아이패드·안드로이드 브라우저에서 테니스공 포물선 운동 영상을 한 프레임씩 넘기며 위치를 기록한다. 영상은 기기 안에서만 처리되고 서버로 전송되지 않는다.

- `phase0/` — 0단계: 기기별 프레임 단위 이동 검증 페이지
- `tools/` — 테스트 영상 생성(`make_test_video.py`), 파서 테스트(`node tools/test_mp4meta.mjs`)
- `PLAN.md` — 개발 계획과 진행 기록
