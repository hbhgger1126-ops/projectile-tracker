0단계: 프레임 이동 검증

이 기기의 브라우저에서 영상을 한 프레임씩 정확하게 넘길 수 있는지 확인하는 시험 페이지입니다. 영상은 이 기기 안에서만 처리되고 어디에도 올라가지 않습니다.

검사 순서

  1. 테스트 영상 열기로 먼저 검사합니다. 화면 속 FRAME 번호와 아래 프레임 번호가 같은지 보고 자동 검사를 누릅니다.
  2. 이 기기 카메라로 계속 움직이는 장면(손 흔들기, 공 던지기 등)을 5초쯤 찍습니다. 아이패드는 설정 > 카메라 > 비디오 녹화를 1080p 60fps로 맞춰 주세요.
  3. 찍은 영상을 영상 고르기로 열고 자동 검사를 누릅니다. 아이패드는 같은 영상을 사진 보관함에서 한 번, 파일 앱에서 한 번 열어 해상도·파일 크기가 같은지 비교합니다.
  4. 바로 촬영하기로 찍은 영상도 한 번 검사합니다.
  5. 맨 아래 결과 복사를 눌러 내용을 보내 주세요(또는 화면을 캡처해 주세요).
